# Android #3007 Direct Image Sources

- Extend the image-only pipeline from Sogou to the three direct adapters named by the Android reference: Sogou (new in that reference PR), existing Brave API images and existing two-step DuckDuckGo images. Reuse the actual Keychain credential/settings implementation already in iOS; no second secret store, key editor or credential in model arguments. Explicit engine order is retained, unknown/mixed unsupported engines fail, and automatic candidates omit unconfigured/invalid Brave credentials instead of substituting for an explicit request.
- Brave uses the fixed api.search.brave.com HTTPS image-search path, twenty candidates and moderate safe-search. Require a bounded printable non-whitespace stored key before an explicit Brave request. The optional typed image-header policy rechecks scheme, exact host, default TLS port, no userinfo and exact encoded API path on every redirect hop before supplying X-Subscription-Token. Off-origin/different-path redirects receive no Brave key. Generic callers pass nil; the prior article header policy and all HTTP/body/content/redirect/public-host/timeout/cancellation rules are retained outside that exact header hook. No general custom-header facility was added.
- DuckDuckGo first fetches the fixed landing page, reads only a bounded inert vqd assignment, then builds a fixed HTTPS /i.js URL with URLQueryItem encoding, JSON mode and safe-search parameter. No script execution or response-provided endpoint is used. The second invocation starts at the current time but retains the first invocation's absolute deadline/cancellation, using only remaining time; there is no fresh four-second allowance. Missing/invalid tokens produce a retryable engine-response diagnostic, without a second request or silent fallback. Routine output source metadata describes the actual first landing response rather than publishing the token-bearing second URL; results are parsed from the second JSON response.
- Shared structured JSON parsing preserves original/thumbnail/source URLs and bounded dimensions for Brave and DuckDuckGo, using the existing native HTTPS image-URL policy. Only a missing source URL may fall back to the image URL; a supplied invalid source is rejected rather than invented into a citation. Retain existing Sogou parsing unchanged. This native policy is intentionally stricter about HTTP image bytes than the older Android JSON adapter; discovered metadata does not grant network/tool authority or prove pixels.
