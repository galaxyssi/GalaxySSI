# Embedded UTM SE Runtime Notice

The full offline iOS IPA obtains the UTM SE 4.7.5 runtime from its official release and verifies the published SHA-256 digest before packaging its QEMU frameworks.

UTM source: https://github.com/utmapp/UTM/tree/v4.7.5
UTM QEMU source: https://github.com/utmapp/qemu

UTM is Apache-2.0. QEMU and some embedded runtime components carry GPL or LGPL obligations. The generated IPA retains the upstream framework notices and this source repository documents the fixed upstream release, digest, and source locations used for redistribution.
