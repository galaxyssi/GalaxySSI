# Repository Instructions

## Local-Only Test Evidence

- Do not commit or upload test reports, real-device evidence, screenshots, UI
  dumps, raw experiment results, or private test data to GitHub.
- Keep these materials outside every Git worktree. Do not recreate or force-add
  `docs/testing/`, or move its removed contents elsewhere in the repository.
- Do not attach these materials to pull requests, issues, releases, or workflow
  artifacts. Report only a concise verification outcome without private data.
- Test source code, reusable test tools, and deliberately synthetic fixtures
  remain allowed. Do not remove or disable tests to avoid storing their output.
- Follow `CONTRIBUTING.md` for repository checks and release verification.
