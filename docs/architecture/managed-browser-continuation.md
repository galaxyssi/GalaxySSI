# Managed member browser continuation

## Ownership and enrollment

A new local member dispatch can enroll interactive browser tools only after its
encrypted managed-response ledger and exact team checkpoint agree. The binding
includes supervisor, team, conversation, turn, task, member, provider, delivery
mode, assignment, dependencies and host context. The source is derived from the
original member idempotency key. No ordinary parent workspace or UI Run is
invented to make a member look like a single-agent task.

Research members additionally need the original live group and exact evidence
binding. Their browser and dependency-setup tools augment the scoped research
catalog; they do not gain unrestricted runtime execution or workspace mutation.
Repair-only publication loops retain their existing restricted catalog. Once an
enrolled browser loop starts, publication state cannot change its pinned catalog.

An already prepared journal, including a request saved before the first inference,
prevents enrollment into a different tool catalog. Original single-agent behavior
and legacy managed loops without a browser owner remain unchanged.

## Waiting and recovery

The encrypted handoff persists the managed owner and member source. Returning
control schedules recovery of the original local loop, not a new member task.
Recovery waits for the initial process lease to close, verifies current ownership,
and reopens the original immutable request and encrypted continuation journal.
The returned-control observation is committed before further model inference.

Pause keeps the pending wake without executing tools. Stop settles cancellation
to the original managed member after execution unwinds. A changed or completed
assignment cannot infer again. An unavailable or corrupt checkpoint defers
recovery instead of falling back to the default store or publishing an invented
final failure. If delivery cannot commit, the wake is not acknowledged.

Final results use the original managed-response bus and receipt, never the
ordinary conversation response channel. A receipt committed before dispatch
acknowledgement retires the dispatch without running another model inference.
Sibling members keep independent browser scopes, journals and response owners.

## Verification boundary

Pure ownership tests and Android framework fixtures cover member separation,
encrypted reload, exact catalog enrollment, request-only journal compatibility,
pause, stop, unavailable checkpoint, fast control return, original observation,
duplicate wake and durable-result recovery. Scripted inference is explicitly a
framework test, not real-provider autonomous website or login acceptance.
Real-provider login, dependency repair and long-duration end-to-end goals still
require separate validation; this increment does not claim those are complete.
